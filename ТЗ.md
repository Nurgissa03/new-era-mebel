## О проекте

Семейная бригада по сборке мебели: отец и сын, город **Туркестан** (Казахстан). Сайт бесплатный, для семьи.

- **Клиенты** видят красивый сайт, считают цену и оставляют заявку.
- **Один админ — брат.** У него на телефоне кабинет: заявки, статусы, цены, фото работ.
- **Telegram не используем вообще.** Уведомления брату приходят как push-уведомления сайта-приложения (PWA).
- Язык сайта: русский. Валюта: ₸ (тенге).

## Технологии (обязательно)

- **Хостинг:** GitHub Pages (адрес `*.github.io`, потом можно свой домен). Значит, сайт **статический**.
- **Фронтенд:** Vite + React + TypeScript. Роутинг должен работать на GitHub Pages (HashRouter или 404.html-фолбэк).
- **Деплой:** GitHub Actions, автоматическая сборка при push в `main`.
- **Бэкенд:** Supabase:
  - Postgres: заявки, цены, настройки, портфолио, отзывы, push-подписки;
  - Auth: вход брата по email и паролю, **регистрация новых пользователей выключена**;
  - Storage: фото от клиентов и фото работ;
  - Edge Functions: отправка push-уведомлений;
  - RLS на всех таблицах.
- **PWA:** manifest, иконки, service worker, Web Push (VAPID). На iPhone push работает только после «Добавить на экран „Домой“», это нужно объяснить брату на экране кабинета.

## Дизайн

В папке `design/` лежат макеты. Это HTML-файлы особого формата: разметка внутри `<x-dc>`, логика в `<script type="text/x-dc">`. Используй их как **точный образец** внешнего вида, текстов и поведения, но перепиши на React.

| Файл | Что это |
|---|---|
| `Main.dc.html` | Сайт для клиентов, компьютер (адаптив под телефон — медиазапросы там же) |
| `Mobile.dc.html` | Главный экран сайта на телефоне |
| `Admin.dc.html` | Кабинет брата: заказы |
| `Prices.dc.html` | Кабинет брата: цены |

Стиль:
- фон `#07080A`, текст `#EEF0F3`, серый `#A3A9B3` / `#9AA1AC`, акцент `#4C8DFF`. Текст на акцентных кнопках тёмный (`#07080A`);
- шрифты (Google Fonts, с кириллицей): **Unbounded** для заголовков, **Manrope** для текста, **JetBrains Mono** для меток и цифр;
- сделай цвета CSS-переменными, чтобы акцент менялся в одном месте.

### Главный эффект: точки (обязательно перенести)

Логика есть в `Main.dc.html`, методы `buildShapes` и `runDots`. Перенеси её в отдельный React-компонент на `<canvas>`:
- на весь экран (`position: fixed`) летают белые точки (около 12% акцентного цвета) и фоновые точки с параллаксом;
- у каждой секции есть `data-scene` (`wardrobe`, `bed`, `kitchen`, `table`, `bolt`, `scatter`) и `data-side` (`left`/`right`). При прокрутке точки **собираются в силуэт мебели** текущей секции и перетекают в следующую; в `scatter` рассыпаются по экрану;
- при быстрой прокрутке точки «тянутся» за страницей и возвращаются на место (пружина), рисуются короткие хвосты движения;
- у курсора точки разбегаются, к ближним тянутся тонкие линии; по клику разлетаются волной;
- на телефоне фигура по центру и бледнее; в `Mobile.dc.html` фигуры меняются сами по кругу;
- уважай `prefers-reduced-motion`; держи 60 fps (typed arrays, без лишних аллокаций в кадре); останавливай анимацию, когда вкладка скрыта.

## Сайт для клиентов (разделы, как в макете)

1. **Шапка:** логотип NEW ERA MEBEL, ссылки на разделы, кнопка «Оставить заявку».
2. **Главный экран:** «Соберём мебель точно.», кнопки «Рассчитать стоимость» и «Позвонить».
3. **Услуги:** 6 карточек, цена «от …» берётся **из базы**.
4. **Как это работает:** 4 шага.
5. **Калькулятор** (цены из базы):
   `итог = цена_вида × кол-во`
   `+ (этаж − 1) × доплата_за_этаж × кол-во`, если лифта нет
   `+ цена_вида × процент_разборки / 100 × кол-во`, если нужна разборка.
   Если брат выключил показ цен, калькулятор скрыт, а вместо цен пишем «Цена — по звонку».
6. **До / после:** слайдер-шторка, вкладки проектов. Фото берутся из портфолио (брат загружает сам).
7. **Мой заказ:** клиент вводит **телефон и номер заказа** и видит этап: Принят → Едут → Собирают → Готово. Сделай через RPC-функцию Supabase, которая возвращает **только статус** и только при совпадении обеих величин. Список заказов наружу не отдавать.
8. **Отзывы:** показываем только одобренные братом.
9. **О нас:** отец и сын, фото.
10. **Вопросы:** аккордеон.
11. **Заявка:** имя, телефон, адрес, дата, время (утро / день / вечер), что собрать, фото (до 5 шт., сжимать на клиенте), комментарий. После отправки: экран «Заявка отправлена» и **номер заказа**. Защита от спама: honeypot-поле и ограничение частоты.
12. **Подвал:** телефон, WhatsApp, часы работы. На телефоне снизу закреплены кнопки «Позвонить» и «Заявка».

## Кабинет брата (`/admin`, только после входа)

Сделан как мобильное приложение, крупные кнопки, всё в пару нажатий.

- **Заказы:** новая заявка сверху (Принять / Позже), вкладки «Сегодня / Завтра / Все», карточка заказа: время, что собрать, адрес, клиент, сумма, фото. Кнопки: **Позвонить** (`tel:`), **Маршрут** (открыть адрес в 2GIS / картах), **следующий статус** (Новый → Еду → Собираю → Готово).
- **Цены:** редактирование цен по видам мебели, доплаты (за этаж, % разборки), переключатель «Показывать цены на сайте», кнопка «Сохранить». После сохранения сайт сразу показывает новые цены.
- **Календарь:** заказы по дням.
- **Фото работ:** загрузить пару «до / после» с телефона, подпись, удалить. Сразу видно на сайте.
- **Отзывы:** одобрить или скрыть.
- **Деньги:** сумма выполненных заказов за неделю и месяц (считать по заказам со статусом «Готово»).
- **Уведомления:** кнопка «Включить уведомления» (подписка Web Push) и инструкция для iPhone.

## База данных (предложение, можешь улучшить)

- `orders`: id, public_code (короткий номер для клиента), name, phone, address, date, time_slot, item_type, qty, floor, has_lift, needs_dismantle, comment, photos[], estimated_price, final_price, status (`new` | `on_way` | `assembling` | `done` | `cancelled`), created_at.
- `prices`: item_type, label, price, sort_order.
- `settings`: floor_fee, dismantle_pct, show_prices, phone, whatsapp, work_hours.
- `portfolio`: id, title, before_url, after_url, sort_order, visible.
- `reviews`: id, name, text, item, approved, created_at.
- `push_subscriptions`: endpoint, keys, created_at.

RLS:
- аноним может **только** читать prices, settings, portfolio (visible), reviews (approved); создавать orders и reviews (approved = false);
- всё остальное доступно только авторизованному админу.

Push:
- Database Webhook на INSERT в `orders` → Edge Function `notify-new-order` → Web Push на все подписки брата: «Новая заявка: шкаф, 2 шт, завтра утром».

## Этапы

1. **Подготовка:** объясни, как создать репозиторий на GitHub и проект в Supabase, какие ключи куда вставить (URL и anon key в `.env` и в GitHub Secrets).
2. **Каркас + деплой:** пустой сайт открывается по адресу `*.github.io`.
3. **Сайт для клиентов:** дизайн + эффект точек, пока с тестовыми данными.
4. **База данных:** таблицы, RLS, цены и заявки работают по-настоящему.
5. **Кабинет брата:** вход, заказы, статусы, цены, фото работ, отзывы, деньги.
6. **PWA и уведомления:** установка на телефон, push о новой заявке.
7. **Проверка:** пройди путь клиента и путь брата на телефоне; проверь, что аноним не может читать чужие заявки.
8. **Инструкция для брата:** короткая страница или файл: как войти, установить на телефон, включить уведомления, поменять цены, добавить фото.
